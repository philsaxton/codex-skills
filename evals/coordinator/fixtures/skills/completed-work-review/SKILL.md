# Completed work review

Evaluation fixture only. Assignment-preparation cases use this stand-in to check that completed-deliverable review selects an appropriate skill instead of `contract-reviewer`. It is not a shipped reviewer skill.

Read the current deliverable and agreed requirements directly. Inspect actual output even when a test receipt says checks passed. Identify which observed behavior satisfies or conflicts with each relevant requirement and what remains unverified. Return findings and a scoped conclusion; do not edit, accept requirements changes, or approve release.
